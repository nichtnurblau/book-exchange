# Contributing

Спасибо за участие в разработке проекта.

## Общие правила

- Перед началом работы обновите локальную версию репозитория.
- Для каждой задачи создавайте отдельную ветку.
- Не вносите изменения напрямую в ветку `main`.
- Один коммит должен содержать одно логически завершённое изменение.
- Названия коммитов должны кратко описывать сделанную работу.
- Перед отправкой изменений убедитесь, что проект запускается без ошибок.

## Работа с ветками

Рекомендуемый формат названий веток:

```text
feature/add-book
feature/exchange-request
fix/login-error
docs/update-readme
