# Работа над проектом

- Код приложения находится в `src`, проверки — в `tests`, документация — в `docs`.
- Импорты собственных модулей начинаются с `src`.
- Репозитории отвечают за хранение, сервисы — за правила, CLI — за ввод и вывод.
- Сохраняйте аннотации типов и короткие docstring. Вспомогательные методы размещайте после публичных.
- Проверяйте предлагаемые ИИ-инструментами изменения и разбирайтесь в их работе перед включением в проект.
- Перед коммитом выполните `python -m unittest discover -s tests -v` и проверки Ruff.
- Для изменений создавайте отдельную ветку и Pull Request. Не публикуйте пароли, `.env` и рабочие данные.
