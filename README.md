## 1\. Общие сведения

### 1.1. Наименование проекта

Полное наименование: «Платформа для обмена книгами между пользователями». Краткое название: «Книгообмен».

### 1.2. Основание для разработки

Программа разрабатывается в рамках лабораторных работ по дисциплине «Программная инженерия».

### 1.3. Заказчик, пользователи и исполнители

Проект учебный, внешнего коммерческого заказчика нет. Требования и результат оценивает преподаватель дисциплины. Предполагаемые пользователи — студенты и другие читатели, которые хотят обменивать свои бумажные книги.

Работу выполняет команда из трёх студентов группы ИВТ-262. Ответственный участник ведёт репозиторий и передаёт преподавателю ссылку на проект.

### 1.4. Цель и исходные данные

Цель разработки — создать простое веб-приложение, в котором пользователь может предложить свою книгу, найти чужую и договориться об обмене.

Исходные данные: сведения о пользователях, названия и авторы книг, жанры, состояние экземпляров, города и заявки на обмен. Во время разработки и проверки используются вымышленные учётные записи и тестовые объявления.

### 1.5. Состав и сроки работ

В первой лабораторной работе определяются назначение, основные функции и ограничения программы. Далее планируется уточнить требования, спроектировать базу данных и интерфейс, реализовать приложение и проверить его работу. Сроки выполнения определяются учебным графиком. Финансирование и платные сервисы для учебной версии не требуются.

## 2\. Назначение программы

### 2.1. Решаемая задача

После прочтения книги часто остаются без использования. Найти человека, которому нужна такая книга и который готов предложить свою, через обычную переписку неудобно: объявления теряются, а доступность приходится уточнять отдельно.

Программа должна объединить объявления в одном каталоге и позволить отправлять предложения об обмене. Ожидаемая польза — повторное использование книг и сокращение времени на поиск подходящего предложения.

### 2.2. Функциональное и эксплуатационное назначение

Платформа предназначена для размещения и поиска объявлений, отправки заявок и учёта результата обмена. Пользователь работает с ней через браузер. Учебная версия демонстрируется на одном компьютере с локально запущенным приложением.

Передача бумажных книг выполняется самими участниками вне приложения. Программа хранит договорённость и её статус, но не организует доставку.
