# Веб-приложение

Запуск всей системы: `docker compose up --build -d --wait`.
Адрес: http://localhost:8000, OpenAPI: http://localhost:8000/docs.

Гость просматривает каталог, регистрируется и входит. Пользователь добавляет
книги в разделе «Мои книги», предлагает обмен в каталоге и отвечает в «Моих заявках».
Контакт другого участника открывается после принятия заявки. Для завершения
каждый из двух участников отдельно подтверждает передачу.

Для проверки откройте обычное окно и приватное окно браузера, зарегистрируйте
двух пользователей и добавьте по книге. Первый предлагает обмен, второй принимает,
затем оба подтверждают. Обе книги получают статус «Обменена».

`docker compose ps` показывает готовность приложения и БД.
`docker compose logs app` показывает ошибки старта.
`docker compose down` останавливает систему, сохраняя том с данными.
Повторный `up` использует прежнюю БД. `down -v` удаляет данные.

Тесты: `uv run python -m unittest discover -s tests -v`.
Проверка работающей Docker-сборки: `uv run python -m tests.smoke_web`.
GitHub Actions запускает миграции и тесты, собирает образ, дожидается готовности
веб-приложения и выполняет обмен через HTTP API на PostgreSQL.
